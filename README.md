# EduFSM

**Learn how computers make decisions over time.**

EduFSM is a bilingual, beginner-friendly course and toolkit for finite state machines (FSMs), automata, sequential logic, software state machines, protocols, testing, and HDL/FPGA design.

Norwegian is the primary course language, with English maintained in parallel.

## What you learn

EduFSM progresses from states, events, and transitions through DFA/NFA, Moore and Mealy machines, sequential digital logic, software implementations, protocols and parsers, HDL/FPGA, and systematic analysis and testing.

The wider learning path is:

`EduNumbers -> EduBoolean -> EduFSM -> EduCPU`

## Interactive simulator

EduFSM includes a static browser simulator with:

- editable FSM source;
- deterministic execution;
- valid-event controls and transition history;
- transition table and state diagram;
- reachability analysis;
- trace export, import, and replay.

The browser core is checked against conformance data generated by the Python reference implementation.

## Command-line toolkit

Install the project in a Python 3.10+ environment and use the `edufsm` command.

Examples:

```sh
edufsm run examples/turnstile.fsm coin push
edufsm table examples/turnstile.fsm
edufsm graph examples/turnstile.fsm
edufsm analyze examples/turnstile.fsm
edufsm model-test examples/turnstile.fsm --runs 10 --steps 100 --seed 0
edufsm hdl examples/turnstile.fsm --target systemverilog
```

The toolkit also supports DFA/NFA operations, Moore/Mealy machines, trace/replay, software code generation, state encoding, truth tables, and SystemVerilog/testbench generation.

## Publishing

The course is built from shared Markdown sources and explicit Norwegian and English book manifests.

```sh
make all
```

The publishing pipeline produces:

- HTML/web course;
- EPUB;
- Kindle-friendly EPUB;
- PDF;
- generated Graphviz diagrams;
- generated Norwegian and English exercise collections.

GitHub Pages also publishes the course and interactive simulator.

## FPGA qualification

M7 includes synthesizable SystemVerilog, an automated testbench, and FPGA toolchain qualification through the reusable Ploos-AS hardware CI workflow. Automated FPGA qualification is separate from physical-board qualification.
